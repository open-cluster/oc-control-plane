OpenCluster is an open-source AI SRE for operational questions and incident investigations. Connect metrics, logs, traces, infrastructure, source control, and collaboration services to understand what is happening and what changed.

Ask a question in a Conversation or investigate an Incident. Conclusions include cited Findings, recommended actions, and explicit limitations. OpenCluster recommends production changes for human review. It does not execute them.

The current self-hosted deployment is API-only. Start with the [Quickstart](/getting-started/quickstart) for the product workflow and links to supported setup. [Feature availability](/feature-availability) describes what ships.
