---
title: "OpenCluster"
description: "Connect operational systems, investigate incidents with read-only evidence, and review cited findings."
---

OpenCluster connects to the alerting, infrastructure, collaboration, and source-control
systems you already use. It investigates Incidents with bounded read-only access and
returns cited Findings, explicit limitations, and proposed next steps for a person to
review.

OpenCluster does not execute production changes. Each material claim cites the numbered
Tool Run that supports it, and each Action Proposal states its risk, reversibility,
approval requirement, and verification procedure.

Start with the local end-to-end path, choose the systems that can supply evidence, or
browse the HTTP contract. [Feature availability](/feature-availability) distinguishes
what ships in OSS v0.1 from what is unavailable.
