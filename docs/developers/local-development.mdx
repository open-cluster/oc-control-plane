---
title: "Local development"
description: "Build and test the control plane with Go, Docker, and the repository verification gates."
---

Install the versions named by the repository toolchain and ensure Docker is reachable. Clone the control plane, copy `.env.example`, create local secret files, and run the short unit suite before container-backed tests.

Use `make test-short` for unit tests, `make test` for race-enabled tests with real PostgreSQL containers, and `make verify` for the complete CI gate. The repository does not ship a native Windows wrapper; use GNU Make and a POSIX shell or run the Makefile commands explicitly.

The root Go module contains the shipping service. `test/e2e` is a separate Go module for
real-process control-plane and Relay proofs; the shipping module must not acquire its
dependencies. Run `make tools` once to install the pinned analysis commands.

Before opening a pull request, confirm Docker is reachable, no generated or secret file
entered the diff, and `make verify` passes. See [Contributing](/developers/contributing)
for the required handoff evidence.
