title: "Repositories"
description: "Find the public repositories that make up the shipped OpenCluster system."
---

| Repository | Ownership |
| --- | --- |
| [`open-cluster/oc-control-plane`](https://github.com/open-cluster/oc-control-plane) | Product HTTP contract, durable domain state, provider Integrations, Investigation engine, Relay protocol support, self-hosting assets, and public documentation. |
| [`open-cluster/oc-relay`](https://github.com/open-cluster/oc-relay) | Customer-side execution and outbound cluster connectivity for the released Relay protocol. |

The browser interface may be shipped from a separate public frontend repository, but this
repository's Compose path includes the supported frontend artifact and same-origin routing.
Private Cloud and Enterprise composition repositories are not part of the OSS dependency
chain and are not listed here.

Use the [architecture overview](/developers/architecture) to understand the boundaries
before choosing a repository. Repository availability and names may change before the
first stable release; follow links from the
[OpenCluster organization](https://github.com/open-cluster) rather than guessing a private
or future repository.
