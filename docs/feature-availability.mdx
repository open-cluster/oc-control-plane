title: "Feature availability"
description: "See which OpenCluster v0.1 capabilities are available in the independently usable OSS edition."
---

| Capability | OSS v0.1 availability |
| --- | --- |
| Local authentication and generic OIDC | Available |
| Organization isolation and fixed Roles | Available |
| Generic Webhook and Alertmanager intake | Available |
| Kubernetes Relay, GitHub, and Slack read Tools | Available |
| Anthropic and Z.AI deployment-level BYOK | Available |
| Bounded Investigations, citations, and Conversations | Available |
| Draft Postmortems for resolved Incidents | Available |
| Action execution | Not available; proposals are never executed |
| Organization-level BYOK, billing, managed provisioning, and enterprise directory controls | Not part of OSS v0.1 |

Availability describes shipped user outcomes, not future commitments. Check the release notes for the exact version you deploy.
