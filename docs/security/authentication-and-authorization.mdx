---
title: "Authentication and authorization"
description: "Use local authentication or generic OIDC with opaque sessions and Organization-scoped permissions."
---

The one-time local bootstrap creates the first User and an opaque cookie session. The authenticated User then creates the first Organization through `POST /api/v1/organizations`.

Audit records are Organization-owned. Because bootstrap deliberately runs before any
Organization exists, it cannot create a tenant audit event. The first auditable mutation
is the atomic Organization creation and Admin-membership grant. Protect and retire the
file-backed bootstrap token after that one-time use.

Normal product routes use the opaque `__Host-oc_session` cookie. General bearer API tokens are not shipped in v0.1. Unsafe cookie requests require the configured same-origin `Origin`; cross-origin and `Origin: null` requests are rejected.

Roles grant fixed Permissions inside an Organization. Missing authentication returns `401`; insufficient Permission returns `403`; inaccessible Organizations and unknown tenant records are indistinguishable.
