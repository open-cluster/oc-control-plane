---
title: "AI provider data flow"
description: "Understand the bounded context sent to a configured model provider."
---

For an Investigation, OpenCluster may send the subject, question, bounded time window, connected Tool catalog, normalized alert context, bounded prior cited Findings, and summarized Tool results to the configured model provider.

The provider returns Tool requests or a structured conclusion. OpenCluster validates budgets, citations, enums, and result bounds before persistence. Raw credentials, system secrets, and model chain-of-thought are not part of the public result contract.

Review the selected provider's retention, training, regional processing, and contractual terms before production use.

For example, a question about checkout latency may send the normalized alert, bounded
GitHub and Kubernetes Tool summaries, and prior cited Findings. The provider can request
another allowed Tool or return a typed conclusion; it never receives a Tool credential.

Redaction and bounded context reduce exposure but do not make provider processing local.
Choose a permitted provider and region, restrict source content, and treat returned text
as untrusted until schema and citation validation succeed. See
[Model providers and BYOK](/self-hosting/model-providers-and-byok).
