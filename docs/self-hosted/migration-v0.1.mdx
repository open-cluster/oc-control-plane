---
title: "Migrate to v0.1"
description: "Recreate a pre-release installation on the supported v0.1 API, configuration, and Relay contracts."
---

Version 0.1 is a clean break from development builds. Back up anything you need to retain,
then Recreate the PostgreSQL database instead of attempting an in-place schema upgrade.

## Before you start

1. Export any Incident or Investigation information you need to retain.
2. Stop the previous control plane and Relay processes.
3. Keep copies of your file-backed credentials. Do not copy credential values into environment variables.

## Recreate the deployment

1. Create an empty PostgreSQL database and place its DSN in a protected file.
2. Set `OC_DATABASE_DSN_FILE` to that file path and review the remaining supported keys in [Configuration](/self-hosted/configuration).
3. Start the v0.1 composition. It serves the frontend and control plane as separate containers on one browser origin.
4. Bootstrap the first administrator and create new Integrations.
5. Re-enrol each Relay with a newly issued bootstrap token so protocol compatibility is recorded.

Update clients to use authenticated product routes under `/api/v1`. Configure alert sources
to send inbound requests under `/webhooks/v1`; do not send an Organization selector on those
public intake routes.

Verify the result with `/healthz` and `/readyz`, then send one test alert through every inbound Integration.
