---
title: "Configuration"
description: "Every environment variable, grouped by what it enables — and the rules that keep a misconfiguration from starting."
---

Configuration is environment variables, validated at startup: the first problem refuses
the start and names the offending variable. No environment value ever carries a
credential — every secret is a **file** the variable names — and no error quotes a
secret file's contents.

## By what it enables

| To enable | Set |
| --- | --- |
| The process at all | `OC_HTTP_ADDRESS`, `OC_PLACEMENTS`, and `OC_DEFAULT_PLACEMENT` or `OC_PLACEMENT_ASSIGNMENTS` |
| Relays (Kubernetes) | `OC_RELAY_ADDRESS` + `OC_RELAY_SPKI_PINS` |
| The operator surface | `OC_OPERATOR_ADDRESS` + `OC_OPERATOR_TOKEN_FILE` + `OC_OPERATOR_TOKEN_ORGANIZATION` |
| Browser sign-in | `OC_OPERATOR_PUBLIC_URL`, `OC_OPERATOR_CONSOLE_URL`, `OC_OPERATOR_ALLOWED_ORIGINS`, `OC_SEALING_KEY_FILE` |
| Alert intake | `OC_INTAKE_ADDRESS` (+ `OC_INTAKE_PUBLIC_URL` so webhook endpoints render whole) |
| Credential-bearing integrations (Slack) | `OC_SEALING_KEY_FILE` |
| GitHub | `OC_GITHUB_APP_ID` + `OC_GITHUB_APP_PRIVATE_KEY_FILE` (both or neither); `OC_GITHUB_API_URL` for Enterprise hosts |
| Investigations | `OC_MODEL_PROVIDER`, `OC_MODEL_NAME`, `OC_MODEL_KEY_FILE`, `OC_MODEL_CONSENTED_PROVIDERS` |

## The full table

| Variable | Required | Meaning |
| --- | --- | --- |
| `OC_HTTP_ADDRESS` | yes | Listen address for health, readiness and metrics |
| `OC_PLACEMENTS` | yes | `name=path-to-dsn-file` pairs, comma separated |
| `OC_DEFAULT_PLACEMENT` | one of these two | Placement serving organizations with no explicit assignment |
| `OC_PLACEMENT_ASSIGNMENTS` | one of these two | `organization=placement` pairs, comma separated |
| `OC_SHUTDOWN_TIMEOUT` | no | Drain budget on SIGTERM. Default `15s` |
| `OC_SERVICE_NAME` | no | Telemetry service name. Default `oc-control-plane` |
| `OC_OTLP_ENDPOINT` | no | Trace collector `host:port`. Empty disables trace export |
| `OC_RELAY_ADDRESS` | no | Listen address for the Relay endpoint. Empty serves no Relays |
| `OC_RELAY_SPKI_PINS` | with relays | This endpoint's public key digests, handed to a Relay at enrolment. Comma separated; more than one so a rotation can overlap |
| `OC_OPERATOR_ADDRESS` | no | Listen address for the operator surface. Empty exposes it nowhere |
| `OC_OPERATOR_TOKEN_FILE` | with operators | File holding the bootstrap credential, at least 32 characters |
| `OC_OPERATOR_TOKEN_ORGANIZATION` | with a token | The one organization that credential reaches. Required, never inferred |
| `OC_OPERATOR_TOKEN_ROLE` | no | The one role it holds there. Default `admin` |
| `OC_OPERATOR_PUBLIC_URL` | with sign-in | Where the operator surface is reachable from a browser; the OIDC redirect URI is built from it |
| `OC_OPERATOR_CONSOLE_URL` | with sign-in | Where a browser is sent once signed in. Must share a registrable domain with the above |
| `OC_OPERATOR_ALLOWED_ORIGINS` | with a console | Browser origins a cookie-authenticated unsafe request may come from. Empty permits none |
| `OC_SEALING_KEY_FILE` | see below | 32-byte key, raw or base64, encrypting stored credentials at rest |
| `OC_SLACK_API_URL` | no | Where the Slack integration reaches its vendor. Empty means Slack's own origin |
| `OC_GITHUB_APP_ID` | with GitHub | The deployment's GitHub App id. Both App variables or neither |
| `OC_GITHUB_APP_PRIVATE_KEY_FILE` | with GitHub | File holding the App's private key, PEM |
| `OC_GITHUB_API_URL` | no | Where the GitHub integration reaches its vendor. Empty means api.github.com; set `https://HOST/api/v3` for GitHub Enterprise Server |
| `OC_MODEL_PROVIDER` | with investigations | The model provider: `anthropic` or `zai`. Empty means investigations refuse to open, with the reason |
| `OC_MODEL_NAME` | with a provider | The exact model identifier, never constructed |
| `OC_MODEL_KEY_FILE` | with a provider | File holding the provider API key |
| `OC_MODEL_EFFORT` | no | How hard the model thinks: `low`, `medium`, `high`, `xhigh`, `max`. Default `high` |
| `OC_MODEL_CONSENTED_PROVIDERS` | with a provider | The providers investigation material may be sent to. Nothing listed permits nothing, including the configured one |
| `OC_MODEL_BASE_URL` | no | Overrides where the provider is reached; https except loopback |
| `OC_MODEL_SPEND_CEILING_CENTS` | no | Hard spend ceiling per investigation, whole cents. Default `500`. Positive only — raisable, never removable |
| `OC_INVESTIGATION_WINDOW_LEAD` | no | How far before the incident began an investigation's window reaches back. Default `2h` |
| `OC_INVESTIGATION_MAX_TOOL_RUNS` | no | Reads per investigation. Default `30`; positive only |
| `OC_INVESTIGATION_MAX_TURNS` | no | Conversation turns per investigation. Default `20`; positive only |
| `OC_INTAKE_ADDRESS` | no | Listen address for alert intake. Empty takes no alerts |
| `OC_INTAKE_PUBLIC_URL` | with intake | The https origin a customer's alerting reaches intake at; webhook URLs are built from it, never from a request's Host header |
| `OC_MINIMUM_RELAY_VERSION` | no | The Relay version floor the fleet summary counts `outdated` against |
| `OC_INVENTORY_INTERVAL` | no | Tick interval requested from every Relay's inventory synchronization. Default `5m`; each Relay floors it locally |
| `OC_CHANGE_LEDGER_RETENTION_DAYS` | no | How many days the change ledger keeps an entry. Default `90` |

## Rules worth knowing

- **Placements.** At least one of `OC_DEFAULT_PLACEMENT` or `OC_PLACEMENT_ASSIGNMENTS`
  is required. An unassigned organization with no default is a hard error, never a
  fallback. A placement's DSN carries a password, so it is read from a file.
- **Half a credential is refused.** A GitHub App id without its key file, a model
  provider without its model name or key — each refuses startup while whoever set the
  first variable is still reading.
- **Consent is explicit.** `OC_MODEL_CONSENTED_PROVIDERS` must name the configured
  provider or investigations refuse to start; an empty list permits nothing.
- **Vendor URLs** (`OC_SLACK_API_URL`, `OC_GITHUB_API_URL`, `OC_MODEL_BASE_URL`,
  `OC_INTAKE_PUBLIC_URL`, `OC_OPERATOR_PUBLIC_URL`) must be https except on loopback,
  because a credential is presented to whatever answers there.
- **The sealing key** is required whenever the deployment serves browser sign-in or a
  credential-bearing integration type (Slack). Rotating it makes stored credentials
  unopenable; each then verifies as failed with "paste it again to replace it" —
  re-paste, don't panic. See [credential handling](/security/credentials).
- **The spend ceiling** ends an investigation that reaches it as an honest partial
  conclusion labeled `spend` — see
  [how investigations work](/investigations/how-investigations-work).
- **The window lead** widens every investigation's window backwards before the incident
  began, because the change that caused an incident usually landed before it fired.
  Every read is clamped inside the widened window.
