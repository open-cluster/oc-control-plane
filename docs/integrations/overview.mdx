---
title: "Integrations"
description: "Choose alert and evidence sources for OpenCluster."
---

Connect an alert source to create Incidents. Add the evidence sources your team uses to investigate them.

- **Alerts.** [Generic Webhook](/integrations/alerting/generic_webhook) accepts your alert sender's JSON. [Prometheus Alertmanager](/integrations/alerting/alertmanager) sends grouped firing and resolved alerts.
- **Observability.** Connect [Prometheus](/integrations/observability/prometheus) for metrics, [Loki](/integrations/observability/loki) for logs and [Tempo](/integrations/observability/tempo) for traces.
- **Infrastructure.** [Kubernetes](/integrations/infrastructure/kubernetes) provides workloads, Events and container logs through Relay.
- **Changes.** [GitHub](/integrations/source-control/github) provides repository changes, checks and releases.
- **Collaboration.** [Slack](/integrations/collaboration/slack) provides conversation context. An installed app can reply to direct mentions.

Use the API to create and manage Integrations. GitHub and Slack installation also use a browser for provider authorization. Start with [Connect your tools](/getting-started/connect-your-tools).
