Connect GitHub to compare an Incident with commits, pull requests, failed checks, files and published releases.

## Prerequisites

You need the OpenCluster **Admin** role and permission to administer the GitHub App installation. Configure a GitHub App for the deployment. The App needs no webhook.

Set its setup URL to the deployment's public HTTPS origin followed by `/api/v1/integrations/connect/callback` and enable redirect on update. Configure the App ID and a private-key file in [deployment configuration](/self-hosting/configuration#environment-reference). Keep the key on the deployment.

## GitHub App permissions

| Repository permission | Access |
| --- | --- |
| Metadata | Read |
| Contents | Read |
| Pull requests | Read |
| Checks | Read |
| Actions | Read |

## Connect

1. Start the [browser authorization flow](/api-reference/overview#authorize-github-or-slack-in-a-browser) with type `github`.
2. In GitHub, choose the account and select the repositories OpenCluster should read. Confirm the requested permissions.
3. Return to OpenCluster in the same browser session. The redirect URL contains `connect=connected` and the Integration ID when setup succeeds.

Use GitHub's installation settings to change the repository selection. Repeating setup for the same installation in the same Organization refreshes the Integration.

## Verify and use

Read the Integration by ID or call the [verification endpoint](/api-reference/overview#verify-an-integration). Check for `verified` and review `toolAvailability`. OpenCluster reads only repositories selected for the installation, with bounded file, diff and log results. Code search and writes are unavailable.

## Troubleshooting

- **GitHub is unavailable for installation.** Check the App settings, private key and deployment public URL.
- **Setup refused.** Confirm your browser is signed in to OpenCluster and your GitHub account can administer the installation. Restart setup if the link expired.
- **Missing repositories or reads.** Check the installation's repository selection and App permissions, then verify again.
- **Key rotation.** Configure the replacement key, restart and verify before revoking the old key. Uninstalling the App revokes access independently.
