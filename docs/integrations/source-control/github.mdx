---
title: "GitHub"
description: "Investigate code changes and CI failures in selected GitHub repositories."
---

Connect GitHub to answer operational questions about repositories, commits, pull requests, CI checks, files, and releases. Use change history alongside other connected sources during an investigation.

## Prerequisites

You need the OpenCluster **Admin** role and a deployment with [GitHub Connect configured](/self-hosting/configuration#github-app-setup). Sign in to GitHub as the owner of the personal account or GitHub organization where you want to install the App.

## GitHub App permissions

| Repository permission | Access |
| --- | --- |
| Metadata | Read |
| Contents | Read |
| Pull requests | Read |
| Checks | Read |
| Actions | Read |

For GitHub organization installations, also grant **Organization permissions → Members: Read-only** so OpenCluster can verify that you own the organization. If you add this permission to an existing installation, a GitHub organization owner must approve it before connecting again. Personal installations require the personal account owner and do not need the Members permission.

## Connect

1. Start GitHub Connect using the [browser authorization steps](/api-reference/overview#authorize-github-or-slack-in-a-browser).
2. In GitHub, choose the account and select the repositories OpenCluster should read. Install and authorize the App.
3. GitHub returns you to OpenCluster. Keep the same browser session open and confirm that the Integration is verified.

If the App is already installed, [start provider authorization](/api-reference/integration-types/start-provider-authorization) with the installation ID to connect without reinstalling. Use the same option if GitHub returns without selecting an installation. An installation can belong to one OpenCluster Organization. Authorizing it again in that Organization refreshes the Integration.

## After connection

OpenCluster reads only the repositories selected for the installation. For example, ask “What changed in checkout before CI started failing?” OpenCluster can read commits, pull requests, workflow runs, job logs, known files, and releases. Large files, diffs, and logs may be shortened. Code search and writes are unavailable.

## Troubleshooting

- **Connect is unavailable.** Ask your deployment administrator to check the [GitHub App setup](/self-hosting/configuration#github-app-setup).
- **Authorization failed or expired.** Check that you are signed in as the owner in GitHub and that any new App permissions have been approved. Start Connect again.
- **Repositories are missing.** Update the repository selection in GitHub's installation settings, then verify the Integration again.
