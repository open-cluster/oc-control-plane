Connect Loki to find service errors, deployment messages and other log entries during investigations and operational questions.

## Connect

You need the OpenCluster **Admin** role, a Loki endpoint reachable from OpenCluster and permission to run log queries. Use an approved HTTPS URL, including any proxy prefix and excluding the Loki API path. See [network and credential requirements](/security/overview).

Use bearer or Basic authentication with a read-only token. Basic authentication also needs a username. Grafana Cloud uses its Loki username and token. For a trusted endpoint that requires no authentication, select `none` and omit token and username. Legacy bearer configuration with no token remains supported. Supply a tenant ID only when your endpoint requires it.

Use the [Loki configuration example](/api-reference/workflows#loki-configuration) to connect through the API.

## After connection

Creation checks log query access. A valid empty result confirms query access. No separate verification call is needed after successful creation.

Ask “What errors appeared in checkout logs in the last 15 minutes?” You do not need to write LogQL. As an optional advanced query, use labels from your logging setup. For example, `{app="checkout"} |= "error"` selects matching lines when your streams use the `app` label. OpenCluster supports log excerpts with timestamps and stream labels. Loki metric queries, live tailing, and label discovery are unavailable.

A read covers at most the latest 24 hours of the requested interval, up to 200 entries. The start is inclusive and the end exclusive. Retention, query limits and shortened entries can affect what is visible.

## Troubleshooting

- Check the endpoint, token, Basic username and tenant if verification fails.
- If a query returns no entries, check your labels, ingestion delay and retention. For an incomplete result, try a narrower interval or selector.
- To replace the token, PATCH the Integration with its full configuration and the new token. Verify again after changes to the endpoint or tenant. To change a credential-bearing connection to unauthenticated access, Disconnect and create a new Integration. Saved credentials cannot silently carry into that mode.
