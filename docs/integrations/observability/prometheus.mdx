Connect Prometheus to investigate metric changes over the same interval as an alert or operator question.

## Connect

You need the OpenCluster **Admin** role and a Prometheus HTTP API reachable from OpenCluster. Use an approved HTTPS endpoint. If it requires authentication, use a read-only bearer token. The URL may include a proxy prefix, but should exclude the query API path. See [network and credential requirements](/security/overview).

Use the [API session and Origin setup](/api-reference/overview#authentication). Save your configuration in a private file named `prometheus.json`:

```json
{
  "type": "prometheus",
  "name": "Production metrics",
  "configuration": {
    "url": "https://metrics.example.com",
    "bearerToken": "<read-only-token>"
  }
}
```

Omit `bearerToken` if your endpoint allows unauthenticated reads.

```bash
curl --fail-with-body --cookie "$OPENCLUSTER_COOKIE" \
  --header "Origin: $OPENCLUSTER_URL" --header 'Content-Type: application/json' \
  --data @prometheus.json "$OPENCLUSTER_URL/api/v1/integrations"
```

## Verify and use

Creation checks that `vector(1)` returns the expected sample. Check `integration.status` for `verified` and save `integration.id`. To repeat the check, call the [verification endpoint](/api-reference/overview#verify-an-integration).

OpenCluster can discover metric names and run instant and range PromQL queries. Range evaluations cover at most the latest 24 hours of the requested interval. An instant query has one evaluation time. Selectors such as `[60m]` and offsets can still read earlier data, so enforce historical access at the source. Responses can include Prometheus warnings and may be incomplete when limits apply. Native histogram results are unsupported.

## Troubleshooting

- If verification fails, check the base URL, TLS trust, network access and the token's query permission.
- If queries work but discovery fails, check access to the metric name endpoint.
- If a read is incomplete or times out, narrow the expression or interval. Apply query limits and retention at your Prometheus endpoint.
- To rotate credentials, PATCH the Integration with the complete configuration and replacement `bearerToken`. OpenCluster verifies the new token before saving it.
