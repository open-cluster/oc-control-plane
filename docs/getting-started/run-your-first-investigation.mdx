---
title: "Run your first investigation"
description: "Open an Investigation from an Incident and review its cited result."
---

Complete the [Quickstart](/getting-started/quickstart) or use an existing Incident. Connect the relevant [Integrations](/integrations/overview), configure a model provider and check that `/readyz` succeeds. Use an **Editor** or **Admin** [API session](/api-reference/overview#authentication).

## Open and follow an Investigation

Use `GET /api/v1/incidents` to find the Incident ID. If an alert already opened an Investigation, use its ID from the Investigation list. To ask OpenCluster to investigate an existing Incident again, replace the placeholder below:

```bash
curl --fail-with-body --cookie "$OPENCLUSTER_COOKIE" \
  --header "Origin: $OPENCLUSTER_URL" --header 'Content-Type: application/json' \
  --data '{"incidentId":"<incident-id>"}' "$OPENCLUSTER_URL/api/v1/investigations"
```

Save the returned `id` as `INVESTIGATION_ID` and check progress:

```bash
curl --fail --cookie "$OPENCLUSTER_COOKIE" \
  "$OPENCLUSTER_URL/api/v1/investigations/$INVESTIGATION_ID"
```

The lifecycle moves from `queued` to `running`, then to `concluded`, `cancelled` or `failed`. See [event streams](/api-reference/overview#investigation-event-streams) for live progress.

## Review the result

Read the summary, Findings and limitations. Check each material Finding against the [cited observation](/concepts/investigations-and-conversations#inspect-a-cited-observation). Review the effective time bounds and whether the source result or prepared observation was incomplete. Treat proposed actions as recommendations and check their verification steps before acting.

A concluded Investigation can be inconclusive. If a source is missing, verify the Integration and review its permissions. For a follow-up question, open or continue a [Conversation](/concepts/investigations-and-conversations#conversations-and-follow-ups).

To stop work, send an authenticated `POST /api/v1/investigations/{investigation}/cancel` with the Origin header. Cancellation is best effort.
