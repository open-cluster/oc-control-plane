title: "Set up OpenCluster"
description: "Create a deployment, bootstrap the first User, and create your first Organization."
---

A v0.1 setup creates a deployment and selects an Organization as the tenant boundary.

## Prerequisites

Complete [Docker Compose](/self-hosting/docker-compose) or [Helm](/self-hosting/helm).
Keep the one-time bootstrap token available, and confirm `/healthz` and `/readyz` succeed.

## Set up the first administrator

Start the deployment, open the console, and expand **Set up the first administrator**. Enter the one-time bootstrap token, your name, email, and password. Bootstrap creates your User and session only.

Next, enter an Organization display name. OpenCluster generates its canonical identifier and grants your membership the Admin Role. Use that Organization selector for every tenant-owned request.

Verify that the console shows your display name, the Organization display name, and the
Admin Role. A second bootstrap attempt should return a conflict. If Organization creation
fails, keep the current session and correct the display name or requested slug; do not
repeat bootstrap.

For production, use same-origin routing, HTTPS, mounted secret files, PostgreSQL persistence, and a configured model provider. Continue to [Connect your tools](/getting-started/connect-your-tools).
