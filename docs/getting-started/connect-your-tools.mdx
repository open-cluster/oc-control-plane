---
title: "Connect your tools"
description: "Connect an alert or evidence source and check its access."
---

Choose an [Integration](/integrations/overview) that can answer an on-call question or deliver your alerts. For a first Investigation, start with one alert source and one relevant evidence source.

1. Sign in as an **Admin**. Set up your [API session and Origin](/api-reference/overview#authentication).
2. Follow your Integration's guide to create it through the API or authorize it in the provider. Kubernetes requires a connected Relay.
3. Verify access using the procedure in the guide. For an alert Integration, send a test delivery first. For an evidence Integration, check the available reads in `toolAvailability`.

Admins can create or remove Integrations. Editors and Admins can update and verify them. Verification checks current access and does not require the source to contain data matching your Incident.

Store one-time webhook secrets as credentials. When rotating a secret, update the sender promptly. Disable an Integration to stop new use while preserving history. Deletion is refused while retained records depend on it. See [Security](/security/overview) for credential and network requirements.
