OpenCluster uses safe defaults for server addresses, local authentication, logs,
telemetry, investigation limits, concurrency, retention, retries, request timeouts, and
shutdown. A normal installation supplies database, AI, and encryption files plus its
public URL. Supply the bootstrap credential only for initial setup, then remove it.

Use environment settings at startup. For each secret, supply either the direct value or
its optional `_FILE` path. Setting both stops startup with a redacted error. Mounted
files work with Kubernetes Secrets and external secret managers without an additional
client in OpenCluster.

## Minimal configuration

```sh
export OC_DATABASE_DSN_FILE=/run/secrets/postgres_dsn
export OC_BOOTSTRAP_TOKEN_FILE=/run/secrets/operator_token
export OC_ENCRYPTION_KEY_FILE=/run/secrets/sealing_key
export OC_AI_PROVIDER=anthropic
export OC_AI_MODEL=claude-sonnet-5
export OC_AI_API_KEY_FILE=/run/secrets/model_key
controlplane
```

Direct alternatives are the same names without `_FILE`, for example `OC_AI_API_KEY`.
Supply these through your deployment's secret tooling. Remove the bootstrap input after
initial setup. Application YAML, `OC_CONFIG_FILE`, and `--config` are retired.

## Applying changes

Configuration and secret files are read once at startup. A file update does not reload
a running process. For Compose, recreate the control plane with
`docker compose -f deploy/compose/compose.yaml up -d --force-recreate control-plane`.
For Helm, ordinary values change the Deployment and trigger rollout. After updating an
existing Secret, run `kubectl rollout restart deployment/<release>-opencluster`, then
`kubectl rollout status deployment/<release>-opencluster`. Confirm `/readyz` and a bounded
Investigation before considering the change complete.

Set `OC_LOG_LEVEL` to `debug`, `info`, `warn`, or `error`; the default is `info`.
Use `OC_OTLP_ENDPOINT` when exporting traces to a collector.
Local authentication is the default. `oidc` adds the configured provider while local
Admin recovery remains available. Relay is optional and listens separately from HTTP;
customer Relays initiate outbound connections and pin the configured control-plane key.
`OC_SESSION_LIFETIME_SECONDS` is deployment-owned and defaults to 43,200 seconds.
Organizations start with 90 days of audit retention and can configure it independently;
browser credential lifetime remains deployment-owned.

## Model provider

OSS v0.1 supports deployment-level Anthropic or Z.AI credentials. Set `OC_AI_PROVIDER`
to `anthropic` or `zai`, set `OC_AI_MODEL` to an exact model identifier accepted by that
provider, and set `OC_AI_API_KEY_FILE` to the mounted credential file. Organization-level
BYOK is not part of the OSS v0.1 contract.

OpenCluster supplies the exact context and maximum output limits for the shipped model IDs:
`claude-sonnet-5`, `claude-opus-5`, `claude-haiku-4-5-20251001`, and `glm-4.7`.
For a custom provider model ID, set both `OC_AI_CONTEXT_WINDOW_SIZE` and
`OC_AI_MAX_OUTPUT_SIZE`. These advanced overrides may lower a shipped model's limits but
cannot exceed its published capacity.

Restart the control plane, wait for `/readyz`, and run one bounded Investigation. Startup
proves that the file is readable; only a completed Investigation proves that the selected
provider and model satisfy the structured result contract. For authentication, quota,
rate-limit, or unsupported-model errors, correct the provider account or model and start
a new Investigation.

OpenCluster sends bounded Investigation context, Tool summaries, and the structured
result contract. It does not persist or expose model chain-of-thought. Review the
[security model](/security/overview) and the provider's retention, regional processing,
and training terms before production use.

## Environment reference

| Variable | Purpose |
| --- | --- |
| `OC_SERVER_ADDRESS` | HTTP listen address; default `:8080`. |
| `OC_PUBLIC_URL` | Browser and webhook origin; default `http://localhost:8080`. |
| `OC_DATABASE_DSN` / `OC_DATABASE_DSN_FILE` | PostgreSQL DSN file. Direct value or file; do not set both. |
| `OC_AUTH_MODE` | `local` or `oidc`. |
| `OC_SESSION_LIFETIME_SECONDS` | Browser session lifetime in seconds; default `43200`, range `300`–`2592000`. |
| `OC_BOOTSTRAP_TOKEN` / `OC_BOOTSTRAP_TOKEN_FILE` | Optional one-time first-User bootstrap token file. Omit after setup to disable initialization. Direct value or file; do not set both. |
| `OC_OIDC_ISSUER` | HTTPS OIDC issuer. |
| `OC_OIDC_CLIENT_ID` | OIDC client ID. |
| `OC_OIDC_CLIENT_SECRET` / `OC_OIDC_CLIENT_SECRET_FILE` | OIDC client-secret file. Direct value or file; do not set both. |
| `OC_RELAY_ADDRESS` | Optional Relay gRPC listen address. |
| `OC_RELAY_SPKI_PINS` | Comma-separated control-plane SPKI pins. |
| `OC_AI_PROVIDER` | Native AI provider: `anthropic` or `zai`. |
| `OC_AI_MODEL` | Exact model identifier. |
| `OC_AI_API_KEY` / `OC_AI_API_KEY_FILE` | AI provider credential file. Direct value or file; do not set both. |
| `OC_AI_CONTEXT_WINDOW_SIZE` | Optional advanced model context-window override; required for a custom model ID. |
| `OC_AI_MAX_OUTPUT_SIZE` | Optional advanced model output-limit override in tokens; required for a custom model ID. |
| `OC_INVESTIGATION_WORKERS` | Concurrent Investigation workers per replica; default `8`. |
| `OC_MAX_PENDING_INVESTIGATIONS_PER_ORGANIZATION` | Maximum unclaimed Investigations per Organization; default `100`. |
| `OC_ENCRYPTION_KEY` / `OC_ENCRYPTION_KEY_FILE` | 32-byte credential-encryption key file. Direct value or file; do not set both. |
| `OC_LOG_LEVEL` | Log level; default `info`. |
| `OC_OTLP_ENDPOINT` | Optional OTLP collector host and port. |
| `OC_SLACK_CLIENT_ID` | Deployment Slack App client ID. |
| `OC_SLACK_CLIENT_SECRET` / `OC_SLACK_CLIENT_SECRET_FILE` | Slack App client-secret file. Direct value or file; do not set both. |
| `OC_SLACK_SIGNING_SECRET` / `OC_SLACK_SIGNING_SECRET_FILE` | Slack request signing-secret file. Direct value or file; do not set both. |
| `OC_GITHUB_APP_ID` | Deployment GitHub App ID. |
| `OC_GITHUB_APP_PRIVATE_KEY` / `OC_GITHUB_APP_PRIVATE_KEY_FILE` | GitHub App private-key file. Direct value or file; do not set both. |

The OSS binary uses one mounted AI deployment for every Organization.

Back up retained installation data before an upgrade. Configuration conversion does not require deleting the database.

The shared HTTP server allows 10 seconds for headers, 30 seconds to read a request,
30 seconds to write a response, and 60 seconds for an idle connection. Restart after a
change, then verify `/healthz`, `/readyz`, sign-in, Organization selection, Integration
verification, and one bounded Investigation.

## Webhook admission limits

Each control-plane process allows a shared burst of 600 webhook requests and restores
10 requests per second before authentication. This protects both alert and Slack intake;
changing an Integration identifier or forwarding header does not create fresh capacity.
During overload, legitimate senders may also receive `429` and must honor `Retry-After`.

After authentication, each Integration has a separate burst of 60 deliveries and restores
one delivery per second. Incorrect credentials do not spend that quota. A process tracks
at most 4,096 active Integrations; additional Integrations receive `429` until an entry
has been idle for ten minutes. Limits are per process and multiply across replicas.
