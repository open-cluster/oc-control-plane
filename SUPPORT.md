# Support policy

No stable control-plane release is published from this repository. Supported deployments,
response commitments, and maintenance windows are defined by the written agreement under
which access is granted.

Authorized users may report reproducible defects through repository issues after removing
credentials and customer data. Report security concerns privately as described in
[SECURITY.md](./SECURITY.md). Questions about configuration belong in an issue or an
existing maintainer-approved support channel.
