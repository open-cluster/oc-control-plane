# Governance

OpenCluster organization owners appoint repository maintainers and retain final authority
over licensing, publication, security disclosure, and release approval.

Maintainers review proposed changes for documented behavior, tenant isolation, credential
safety, domain boundaries, tests, and compatibility with the approved issue. Significant
architecture decisions are discussed on the issue tracker before implementation.

Contributions and releases follow the [Apache License 2.0](./LICENSE). The separately
maintained OpenCluster Relay has its own governance.
